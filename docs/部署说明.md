# 部署说明（给 Muse / 用户）

整个流程：你（或 Muse）在腾讯云和 GitHub 上操作（第一至四部分），Claude 把配置填进代码，最后在真实浏览器里验收（第五部分）。

**仓库名称：** 网页代码仓库与原 OurTrip 仓库互换名称，网页代码仓库叫 `OurTrip`（公开），映射源文件所在仓库叫 `workspace-9`（私有）。GitHub 不允许两个仓库同时同名，互换时需先把其中一个改成临时名称，例如 OurTrip → OurTrip-tmp，workspace-9 → OurTrip，OurTrip-tmp → workspace-9。CORS 来源只填域名 `https://gcy2016.github.io`，不受仓库改名影响。

**要发给 Claude 的只有：** 存储桶完整名称、地域代号、加密工具生成的密文。
**不要发给任何人：** 子用户的 SecretId / SecretKey、共享密码。

---

## 一、腾讯云：开通存储（可以现在做）

1. 登录 [腾讯云控制台](https://console.cloud.tencent.com/)，完成实名认证，开通“对象存储 COS”，领取新用户存储包。
2. **创建存储桶**：对象存储 → 存储桶列表 → 创建存储桶。
   - 名称：自定，例如 `ourtrip`。系统会自动加上 APPID 后缀，完整名称类似 `ourtrip-1250000000`。
   - 所属地域：选离你们近的，例如广州、上海、北京、成都。
   - 访问权限：**私有读写**。
   - 其他选项保持默认。
3. **开启版本控制**：进入存储桶 → 容错容灾管理 → 版本控制 → 开启。
4. **设置生命周期**（旧版本保留 30 天）：进入存储桶 → 基础配置 → 生命周期 → 添加规则：
   - 应用范围：整个存储桶；
   - 历史版本文件：**30 天后删除**；
   - 删除碎片：1 天后（如有此选项）。
   （对应的规则内容见 `cos/lifecycle.json`，控制台里按上述选项勾选即可。）
5. **设置跨域访问（CORS）**：进入存储桶 → 安全管理 → 跨域访问 CORS 设置 → 添加规则：

   | 项目 | 填写内容 |
   |---|---|
   | 来源 Origin | `https://gcy2016.github.io` |
   | 操作 Methods | GET、PUT、POST、HEAD、DELETE |
   | Allow-Headers | `*` |
   | Expose-Headers | `ETag`、`Date`、`Content-Length`、`x-cos-request-id`、`x-cos-version-id`（每行一个） |
   | 超时 Max-Age | `600` |

6. **预算告警**：费用中心 → 预算管理（或“费用告警”）→ 新建，例如月费用超过 5 元时短信/邮件通知。COS 没有硬性的花费上限，这一步很重要。

## 二、腾讯云：创建两个子用户

进入 访问管理（CAM）→ 用户 → 用户列表 → 新建用户 → 自定义创建，**访问方式只勾选“编程访问”**，不要勾选控制台访问。

### 子用户 A（网页用）

1. 用户名例如 `album-web`。
2. 先在 访问管理 → 策略 → 新建自定义策略 → 按策略语法创建，把 `cos/web-policy.json` 的内容原样粘进去（已按存储桶 `ourtrip-1497637272`、地域 `ap-guangzhou` 填好）。策略名例如 `album-web-policy`。
3. 给子用户 A 关联这个策略。
4. 记下子用户 A 的 SecretId 和 SecretKey（只在第四部分的加密工具里使用）。

这个策略只允许读、写和列出这一个存储桶，**不能删除文件，也不能修改存储桶设置**。即使网页里的密钥被别人破解，也删不掉你们的照片和 30 天内的历史版本。

### 子用户 B（维护用）

1. 用户名例如 `album-admin`。
2. 用同样的方式创建策略，内容为 `cos/admin-policy.json`（已填好），策略名例如 `album-admin-policy`，关联给子用户 B。
3. 子用户 B 的密钥**只在维护工具页（`tools/admin.html`）里临时输入**，不放进网页、不放进仓库，平时不需要使用。

## 三、GitHub：发布网页

1. 把网页代码仓库（互换名称后叫 `OurTrip`）改为公开：Settings → General → 最下方 Danger Zone → Change visibility → Public。
2. 开启 Pages：Settings → Pages → Build and deployment → Source 选 “Deploy from a branch”，Branch 选 `main`、目录 `/ (root)` → Save。
3. 1–2 分钟后访问 `https://gcy2016.github.io/OurTrip/`。
4. 完成第四部分后，Claude 收到“存储桶名称、地域、密文”，会把它们填进 `js/config.js` 并提交。填好之前，网页会提示“尚未配置云端存储”，可以先点“进入演示模式”体验。

---

## 四、生成密文（等第三部分网页发布后做）

1. 打开加密工具页：`https://gcy2016.github.io/OurTrip/tools/encrypt.html`
   本页的计算全部在你自己的浏览器里完成，密钥和密码不会发送到任何地方。
2. 填入**子用户 A** 的 SecretId、SecretKey，以及你们两人共用的共享密码（建议 12 位以上，字母和数字混合）。
3. 点“生成密文”，把得到的整段文字发给 Claude（这段可以公开）。
4. 可以点“用密码验证一次”确认密码没有输错。

## 附加：坐标转中文地址（腾讯位置服务，可选）

浏览器定位只能拿到经纬度。要自动转成中文地址，需要一个腾讯位置服务的 Key（与腾讯云账号不同，需单独开通）：

1. 打开 [腾讯位置服务](https://lbs.qq.com/) → 登录（可用微信/QQ）→ 控制台。
2. 应用管理 → 我的应用 → 创建应用（名称随意，例如“旅行相册”）→ 添加 Key。
3. 启用产品勾选 **WebServiceAPI**，校验方式选 **域名白名单**，填 `gcy2016.github.io`。
4. 把生成的 Key 发给 Claude，Claude 填进 `js/config.js` 的 `tencentMapKey`。

说明：
- Key 会写在公开网页里，但设置了域名白名单后，其他网站拿到也用不了。
- 个人开发者有免费调用额度，具体以腾讯位置服务控制台显示为准；两人使用远低于额度。
- 定位时会把坐标发给腾讯位置服务查询地址。未配置 Key 时，此功能自动隐藏，仍可手动填写地址。

## 附加：上传区域名称与地图（Muse 操作）

真实名称不放在公开的网页仓库里，而是放在私有存储桶中，网页登录后读取。地图也一样。

1. 从私有仓库 `gcy2016/file-storage` 下载两个文件：`private/region-map.enc.json`（加密映射文件）和 `china-boundary.svg`（地图）。
2. 打开 `https://gcy2016.github.io/OurTrip/tools/admin.html`，用子用户 B 的密钥连接。
3. 在“区域名称与地图”一栏选择加密映射文件，输入映射文件密码，再选择地图 SVG，点“解密并预览”。密码只在本页使用，不保存、不上传。
4. 预览确认：区域名称 367 个、没有重名；“为区分重名加了省/市/州”中应为 吉林省、吉林市、海南省、海南州；地图 34 个一级区域已对应。没有红色问题提示时点“上传到存储桶”。
5. 回到相册，刷新页面（或菜单 → 刷新数据），首页应显示中文简称，“地图”页可以打开。

以后映射文件或地图有更新，重复以上步骤即可，不需要改网页代码。

地图来源：`china-boundary.svg` 由 DataV.GeoAtlas 全国省级边界数据简化而来（含港澳台；文件中的九段线按 PRD 不显示）。地图仅供两人私用、不对外公开；如将来公开展示，需要改用带审图号的标准地图并注明审图号。

## 五、上线验收（需要在真实浏览器里完成）

Claude 的环境连不上腾讯云，下面这些只能由你们在真实浏览器里验收：

1. 用手机和电脑分别打开网址，输入共享密码进入。输错密码时应提示“密码不正确，请重试”。
2. 一台设备点“开始编辑”，在某个二级区域下新建框、上传几张照片（包括刚拍的原图，以及微信转发过的图）。另一台设备应显示“××正在编辑，你当前只能查看”，约 20 秒内自动看到新内容。
3. 第三台设备（或第三个浏览器）进入时，应提示在线人数已满。
4. 上传过程中把手机切到飞行模式，应显示失败，恢复网络后可以单独重试。
5. 删除一个有照片的末级框，然后打开 `tools/admin.html`，用子用户 B 的密钥连接，在“回收记录”里恢复，回到相册确认照片回来了。
6. 在“地点”里点“获取当前位置”，确认浏览器会请求定位权限、（配置了 Key 时）自动填入中文地址；拒绝定位后仍可手动输入地址。点“在 Apple 地图中打开”，确认能打开 Apple 地图且位置没有明显偏移，返回后相册页面仍在。
7. 上传区域名称与地图后：首页显示简称；“地图”页横向铺满屏幕、按点亮状态着色、点击区域能看到点亮日期，港澳为两个小点、点附近能同时看到两地状态；“时间线”页最新的在最上面。
8. 确认费用中心的预算告警已生效。

## 常见问题

- **打开网页提示“没有访问权限”**：检查第一部分第 5 步的 CORS 来源是否是 `https://gcy2016.github.io`（不要带路径），以及子用户 A 的策略占位符是否已替换正确。
- **更换共享密码**：用加密工具页以新密码重新生成密文，交给 Claude 更新 `js/config.js`。所有设备需要重新输入新密码，“记住此设备”会自动失效。
- **怀疑密钥泄露**：在 CAM 里给子用户 A 新建一对密钥并禁用旧密钥，然后重新生成密文。
- **github.io 打开慢**：先观察实际使用情况；如果确实影响使用，再评估换托管方式（COS 自带的静态网站需要已备案域名）。
